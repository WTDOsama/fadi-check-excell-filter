موقع إيواء فاطمة الزهراء — نسخة تجريبية

التشغيل:
1. فك ضغط الملف.
2. افتح index.html باستخدام Google Chrome.
3. بيانات الدخول الافتراضية:
   اسم المستخدم: admin

الوظائف:
- إضافة الأسر وتعديلها وحذفها.
- حفظ هوية رب الأسرة وهوية الزوجة.
- تسجيل المساعدات وتاريخها وكميتها وحالتها.
- فحص المساعدات باستخدام هوية رب الأسرة أو الزوجة.
- البحث والتصدير إلى CSV الذي يمكن فتحه ببرنامج Excel.
- تغيير كلمة المرور وإضافة مستخدمين محليين.

تنبيه أمني مهم:
هذه نسخة أولية محلية وليست موقعًا منشورًا على الإنترنت. البيانات محفوظة في مساحة التخزين المحلية للمتصفح على الجهاز نفسه، ولا تتزامن بين الأجهزة. كلمات المرور محلية وغير مشفرة. لا تدخل بيانات أسر حقيقية حساسة ولا تستخدمها كنظام إنتاجي قبل إنشاء نسخة بخادم وقاعدة بيانات آمنة وصلاحيات فعلية ونسخ احتياطي.
